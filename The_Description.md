Приложение называется "Лепестки истории".
Оно ищет исторических личностей через API Ninjas.

Имя нужно вводить на английском!!
Можно также выбрать готовую подсказку.
Нажатие на карточку открывает сведения о человеке.
Сердечко добавляет человека в избранное.
Избранное хранится на телефоне и открывается без интернета.
Во вкладке История можно повторить прошлый поиск.
Результаты можно обновить и отсортировать по алфавиту.
Если найдено много людей можно загрузить еще.

Запросы отправляет Dio!!

ApiKeyInterceptor добавляет ключ в заголовок X-Api-Key.
PrettyDioLogger выводит запросы и ответы при отладке.
GetIt хранит зависимости приложения.
SharedPreferences сохраняет избранное и историю.
